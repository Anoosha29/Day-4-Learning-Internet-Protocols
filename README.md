# 📚 Day 4 - Internet Protocols Notes

Today I studied the most important networking protocols: **TCP and UDP**. Here's a summary of what I learned:



✅ Topics Covered:

1. **What is TCP and Why It's Used**
    Reliable, connection-based protocol
    Ensures data is delivered correctly
    Used in web, email, FTP, SSH

2. **TCP 3-Way Handshake**
    Connection setup in 3 steps:
     SYN → SYN-ACK → ACK

3. **What is UDP and Why It's Fast**
    No connection setup
    Very fast but not reliable
    Used in games, streaming, calls

4. **How UDP Works**
   - No handshake or guarantee
   - Just sends data — fire-and-forget style

5. **TCP vs UDP**

| Feature       | TCP                  | UDP                  |
|---------------|----------------------|----------------------|
| Type          | Connection-based     | Connectionless       |
| Speed         | Slower (reliable)    | Faster (unreliable)  |
| Use Cases     | Web, Email, FTP      | Games, Streams, VoIP |
